ArgoCD bootstrap for the cluster

ArgoCD now has a bootstrap path for this repo. It runs from the `default` namespace, serves a locked-down HTTPS endpoint, and then syncs the child Applications that own `shared-infra`, `webpages`, `oci-test`, and `jellyfin`.

Bootstrap command 
kubectl apply -k manifests/argocd/bootstrap
Live route

https://argocd.fsck.me.uk

Child Applications
  • shared-infra for the namespace and shared certificate.
  • webpages for the hosted docs site.
  • oci-test for the hello-world OCI demo.
  • jellyfin for the media server.
First login 
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath='{.data.password}' | base64 -d; echo
Operational note

Use the initial password once, then rotate it. Keep the project destination list and source repo list narrow so the GitOps surface stays predictable.
