Infra

Cloudflare DNS for both public domains

ExternalDNS watches the ingress objects and keeps `fsck.me.uk` and `rghf.nl` aligned with the cluster. The Cloudflare token is stored as a SOPS-encrypted Secret. It must still be valid for the target zones and allowed to authenticate from the server's public IPs.

Managed records
  • fsck.me.uk
  • www.fsck.me.uk
  • rghf.nl
  • www.rghf.nl
Install path 
ssh root@server1.fsck.me.uk
cd /root/k8s_oci
sh scripts/apply-external-dns.sh
Security note

Keep the Cloudflare token encrypted in the repo. Only the age private key should be available on the operator host that applies the secret. If Cloudflare rejects the token, fix the token policy first rather than bypassing the guard.
