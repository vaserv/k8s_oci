Example

Minimal static site image

A static site should be simple: one HTML file, a stylesheet, and a Dockerfile that copies the files directly into the image.

Files 
webpages/
  index.html
  assets/site.css
  docs/
  blog/
  Dockerfile
Dockerfile 
FROM scratch
COPY index.html assets/ blog/ docs/ /
Build and inspect 
docker build -t ghcr.io/your-org/site:dev webpages
docker save ghcr.io/your-org/site:dev -o /tmp/site.tar
tar -tf /tmp/site.tar | head
