Example

Build and publish workflow

The workflow should validate the site before publish, push immutable tags, and skip deploy cleanly when no SSH secret is configured.

Build steps 
docker/setup-buildx-action
docker/build-push-action
docker/login-action
Validation steps 
test -f webpages/index.html
test -f webpages/docs/examples/index.html
test -f webpages/docs/examples/static-site/index.html
Deploy guard 
if [ -n "${SERVER2_SSH_KEY}" ]; then
  echo "enabled=true" >> "$GITHUB_OUTPUT"
else
  echo "enabled=false" >> "$GITHUB_OUTPUT"
fi
