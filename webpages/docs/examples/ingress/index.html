Example

Path-based ingress with HTTPS

The route is public, the redirect is enforced at ingress, and the certificate stays separate from the application manifests.

Ingress snippet 
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: example
  annotations:
    traefik.ingress.kubernetes.io/router.middlewares: k8s-oci-redirect@kubernetescrd
spec:
  ingressClassName: traefik
  tls:
    - hosts:
        - example.rghf.nl
      secretName: example-tls
  rules:
    - host: example.rghf.nl
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: example
                port:
                  number: 80
Redirect middleware 
apiVersion: traefik.io/v1alpha1
kind: Middleware
metadata:
  name: redirect
spec:
  redirectScheme:
    scheme: https
    permanent: true
Verify 
curl -I http://example.rghf.nl
curl -I https://example.rghf.nl
