Step 10: Cloudflare DNS with ExternalDNS

The cluster now carries an external-dns controller that watches ingress objects and keeps the public hostnames in sync with Cloudflare. The controller only works when the token is valid for the managed zones and accepted from the server's public IPs.

What changed
  • Added a Cloudflare token secret encrypted with SOPS and age.
  • Installed ExternalDNS with `fsck.me.uk` and `rghf.nl` domain filters.
  • Documented the root-only key path outside the repo.
Apply flow 
ssh root@server1.fsck.me.uk
cd /root/k8s_oci
sh scripts/apply-external-dns.sh
kubectl -n external-dns logs deploy/external-dns
Security rule

Only the encrypted manifest lives in git. The age private key stays on the operator host or the server, not in the repository. Cloudflare token policy still has to allow the host that runs the controller.
