Step 6: A reusable OCI HTML template

The template exists so the next site does not need a fresh layout, manifest set, or workflow. The site shape is now a repeatable unit.

Template contents
  • Static content directory.
  • Scratch-based OCI build.
  • nginx deployment and ingress manifests.
  • Notes for copying the pattern into future examples.
Build and verify 
docker build -t ghcr.io/your-org/oci-html-template:local templates/oci-html-site
docker run --rm -p 8080:80 ghcr.io/your-org/oci-html-template:local
curl -I http://localhost:8080/
kubectl apply -k manifests/app
Technical detail

Static HTML works well here because it has no runtime state, no package manager, and no extra attack surface beyond the web server that serves the files.
