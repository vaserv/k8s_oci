# Step 2: Bootstrapping the Single-Node Cluster

After installation, the next job is verifying the cluster is actually healthy and ready for workloads.

## What gets checked

- Node status
- System pods
- Ingress controller availability
- Namespace creation for the app

## Operational note

On a small server, the goal is to confirm the control plane is stable before adding cert-manager or the application itself.

## Next step
