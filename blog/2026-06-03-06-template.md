# Step 6: A reusable OCI HTML template

Once the docs site existed, the next useful item was a template that future static sites could copy.

## Template shape

- `site/` for the HTML and CSS
- `Dockerfile` for the OCI image
- `manifests/` for the Kubernetes resources

## Result

The next site should not need a fresh design or a fresh deployment pattern. It should be a copy
of the template with new content, a new image name, and a new ingress target.
