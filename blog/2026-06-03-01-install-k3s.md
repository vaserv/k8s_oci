# Step 1: Installing K3s on a 2 GB Server

The first constraint is memory. On a 2 GB server, the cluster has to stay lean, so the install strips out components we do not need for the MVP.

## Install choice

`k3s` gives us a real Kubernetes control plane with a smaller footprint than a full upstream install.

## What the install script does

- Writes a K3s config file
- Sets the node name to `server2.rghf.nl`
- Disables `servicelb`, `local-storage`, and `metrics-server`
- Installs K3s as a service

## Why those components are disabled

- `servicelb` is not needed because the app will use ingress
- `local-storage` is not needed for the current MVP
- `metrics-server` is useful later, but not essential on a small node

## Outcome

The result is a smaller cluster that still supports the ingress and TLS flow needed for the web app.
