# Step 7: GitHub Actions for build and deploy

The final part of this pass was the CI path.

## Workflow

- Build the HTML image on every relevant change
- Verify the image contains the expected site files
- Push a SHA-tagged image to GHCR on `main`
- SSH into the server and patch the live deployment
- Check the public route after rollout

## Result

The site build is now repeatable and the live server can be updated from a push instead of a manual
image import.
