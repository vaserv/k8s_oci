# Step 4: Shipping OCI Images into Kubernetes

The app should still be deployed as an OCI image, even on a self-hosted node. The registry path does not change just because the server is small.

## Why this matters

- The workload remains portable
- Kubernetes can pull the same image in any environment
- Rollbacks stay simple

## What the deployment uses

- `Deployment`
- `Service`
- `Ingress`
- Readiness and liveness probes

## End state

At this point the app is running behind HTTPS on the self-hosted cluster and the remaining work is hardening and automation.
